# copilot_knowledge — 環境計量業務 AI ナレッジベース

GitHub Copilot / AI エージェント向けの環境計量業務マニュアル集。仕様書から見積・積算に必要な情報を抽出するためのガイドラインをまとめた知識ベース。

## 対象業務

| ファイル | 業務カテゴリ |
|---|---|
| `01_環境計量_DXN測定_焼却炉.md` | ダイオキシン類測定（排ガス・焼却灰・飛灰・作業環境） |
| `02_環境計量_DXN測定_処分場環境.md` | ダイオキシン類測定（放流水・地下水・土壌） |
| `03_環境計量_水質分析.md` | 水質分析（浸出液・地下水・河川水・保有水） |
| `04_環境計量_騒音振動.md` | 騒音・振動調査（廃棄物施設・自動車騒音常時監視） |
| `05_06_環境計量_大気測定_ごみ質_アスベスト.md` | 大気測定・ごみ質分析・アスベスト定性分析 |
| `07_行政事務_補助金審査.md` | 補助金審査・交付事務局運営（住宅用エネルギー・省エネ設備） |
| `08_自然環境_生物調査.md` | 生物移植・モニタリング調査 |

## 使い方

各マニュアルを GitHub Copilot の参照ファイルとして指定することで、業務種別の自動判定・積算項目の抽出精度が向上します。

```
@workspace 仕様書を読み込んで、00_マスターインデックス.md のフローに従い業務種別を判定してください。
```

## 業務種別の自動判定

`00_マスターインデックス.md` に判定フローチャートを記載。キーワード（「ダイオキシン」「排ガス」「騒音」など）から対応するマニュアルファイルを特定できる。
